# 6. Branch Management Commands

---

## Command: git branch

### Syntax

```bash id="c4x3dj"
git branch
```

### Purpose

Lists all the branches available in the current repository and shows the currently active branch.

### Example

```bash id="ry53vd"
git branch
```

---

## Command: git branch -a

### Syntax

```bash id="7z2dzl"
git branch -a
```

### Purpose

Displays all branches including both local and remote branches.

### Example

```bash id="f6jz5t"
git branch -a
```

---

## Command: git branch -d

### Syntax

```bash id="jpn3mj"
git branch -d <branch-name>
```

### Purpose

Deletes a branch that has already been merged with the current branch.

### Example

```bash id="sllq8y"
git branch -d feature
```

---

## Command: git branch -D

### Syntax

```bash id="i81y1r"
git branch -D <branch-name>
```

### Purpose

Force deletes a branch even if it has not been merged.

### Example

```bash id="r01m6k"
git branch -D feature
```

---

## Command: git checkout

### Syntax

```bash id="ppgq9r"
git checkout <branch-name>
```

### Purpose

Switches from the current branch to another existing branch.

### Example

```bash id="7w5r5p"
git checkout develop
```

---

## Command: git checkout -b

### Syntax

```bash id="py4ju8"
git checkout -b <branch-name>
```

### Purpose

Creates a new branch and immediately switches to that branch.

### Example

```bash id="ktp0qk"
git checkout -b feature-login
```

---

## Command: git switch

### Syntax

```bash id="z8q5v1"
git switch <branch-name>
```

### Purpose

Switches to another existing branch.
It is a newer and clearer alternative to `git checkout` for branch switching.

### Example

```bash id="q2e6hu"
git switch develop
```

---

## Command: git switch -c

### Syntax

```bash id="k23hn8"
git switch -c <branch-name>
```

### Purpose

Creates a new branch and switches to it in a single command.

### Example

```bash id="e9yzai"
git switch -c feature-dashboard
```
