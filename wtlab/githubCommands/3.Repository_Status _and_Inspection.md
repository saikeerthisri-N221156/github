# 3. Repository Status & Inspection Commands

---

## Command: git status

### Syntax

```
git status
```

### Purpose

Displays the current state of the working directory and staging area.
It shows which files are modified, staged, or untracked.

### Example

```
git status
```

---

## Command: git log

### Syntax

```
git log
```

### Purpose

Displays the complete commit history of the repository including author name, date, and commit message.

### Example

```
git log
```

---

## Command: git log --oneline

### Syntax

```
git log --oneline
```

### Purpose

Shows the commit history in a compact single-line format where each commit appears in one line.

### Example

```
git log --oneline
```

---

## Command: git log --graph

### Syntax

```
git log --graph
```

### Purpose

Displays the commit history in a graphical representation of branches and merges.

### Example

```
git log --graph
```

---

## Command: git show

### Syntax

```
git show <commit-id>
```

### Purpose

Displays detailed information about a specific commit including changes made in that commit.

### Example

```
git show a1b2c3d
```

---

## Command: git diff

### Syntax

```
git diff
```

### Purpose

Shows the differences between files in the working directory and the staging area.

### Example

```
git diff
```
