# 7. Merge & Integration Commands

---

## Command: git merge

### Syntax

```bash id="e7q1hs"
git merge <branch-name>
```

### Purpose

Combines the changes from another branch into the current branch.
It is commonly used to integrate feature branches into the main or development branch.

### Example

```bash id="y8r4l9"
git merge feature-login
```

---

## Command: git merge --no-ff

### Syntax

```bash id="w8p0na"
git merge --no-ff <branch-name>
```

### Purpose

Performs a merge without fast-forwarding.
This creates a separate merge commit, preserving the history of the merged branch and making the project history clearer.

### Example

```bash id="p6r2cu"
git merge --no-ff feature-login
```
