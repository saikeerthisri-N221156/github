# 15. Debugging Commands

---

## Command: git bisect

### Syntax

```bash id="q2z7dh"
git bisect start
```

### Purpose

Used to perform a binary search through commits to find which commit introduced a bug.

### Example

```bash id="j9r4hf"
git bisect start
```

---

## Command: git bisect start

### Syntax

```bash id="t8p2kn"
git bisect start
```

### Purpose

Marks the start of a bisect session to debug a bug in the project history.

### Example

```bash id="k3v7ql"
git bisect start
```

---

## Command: git bisect good

### Syntax

```bash id="p1r4mv"
git bisect good <commit>
```

### Purpose

Marks a known good commit (without the bug) during a bisect session.

### Example

```bash id="x6q3zr"
git bisect good HEAD~5
```

---

## Command: git bisect bad

### Syntax

```bash id="v9k2aj"
git bisect bad <commit>
```

### Purpose

Marks a known bad commit (contains the bug) during a bisect session.

### Example

```bash id="y3h8tn"
git bisect bad HEAD
```
