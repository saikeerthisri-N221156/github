# 4. File Tracking Commands

---

## Command: git add

### Syntax

```bash
git add <file-name>
```

### Purpose

Adds a specific file from the working directory to the staging area so that it can be included in the next commit.

### Example

```bash
git add index.html
```

---

## Command: git add .

### Syntax

```bash
git add .
```

### Purpose

Adds all modified and new files from the current directory to the staging area.

### Example

```bash
git add .
```

---

## Command: git add -p

### Syntax

```bash
git add -p
```

### Purpose

Allows you to interactively select portions of changes (patches) to add to the staging area instead of adding the entire file.

### Example

```bash
git add -p
```

---

## Command: git restore

### Syntax

```bash
git restore <file-name>
```

### Purpose

Restores a file in the working directory to its previous committed state, discarding local changes.

### Example

```bash
git restore index.html
```

---

## Command: git restore --staged

### Syntax

```bash
git restore --staged <file-name>
```

### Purpose

Removes a file from the staging area without deleting it from the working directory.

### Example

```bash
git restore --staged index.html
```

---

## Command: git rm

### Syntax

```bash
git rm <file-name>
```

### Purpose

Removes a file from both the working directory and the staging area so that it will be deleted in the next commit.

### Example

```bash
git rm oldfile.txt
```

---

## Command: git mv

### Syntax

```bash
git mv <old-file-name> <new-file-name>
```

### Purpose

Renames or moves a file and records the change in Git.

### Example

```bash
git mv file1.txt file2.txt
```
