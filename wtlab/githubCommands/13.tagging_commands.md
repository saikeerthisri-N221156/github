# 13. Tagging Commands

---

## Command: git tag

### Syntax

```bash id="r1f9pa"
git tag
```

### Purpose

Lists all tags in the repository.

### Example

```bash id="w3v8ox"
git tag
```

---

## Command: git tag -a

### Syntax

```bash id="o2p7sd"
git tag -a <tag-name> -m "message"
```

### Purpose

Creates an annotated tag with a name and message.

### Example

```bash id="k4n1za"
git tag -a v1.0 -m "Release version 1.0"
```

---

## Command: git tag -d

### Syntax

```bash id="t5q3lo"
git tag -d <tag-name>
```

### Purpose

Deletes a tag locally.

### Example

```bash id="y9b7ws"
git tag -d v1.0
```

---

## Command: git push origin --tags

### Syntax

```bash id="f3p6nt"
git push origin --tags
```

### Purpose

Pushes all local tags to the remote repository.

### Example

```bash id="h7m4ka"
git push origin --tags
```
