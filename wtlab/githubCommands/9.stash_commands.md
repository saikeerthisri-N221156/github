# 9. Stash Commands

---

## Command: git stash

### Syntax

```bash id="8r0a1m"
git stash
```

### Purpose

Temporarily saves the changes in the working directory and staging area without committing them, allowing you to work on another branch or task.

### Example

```bash id="l1e1te"
git stash
```

---

## Command: git stash list

### Syntax

```bash id="a6ox1s"
git stash list
```

### Purpose

Displays a list of all stashed changes stored in the repository.

### Example

```bash id="25r3zn"
git stash list
```

---

## Command: git stash pop

### Syntax

```bash id="k7d7c5"
git stash pop
```

### Purpose

Applies the most recent stash to the working directory and removes it from the stash list.

### Example

```bash id="4op5cs"
git stash pop
```

---

## Command: git stash apply

### Syntax

```bash id="6d9p53"
git stash apply
```

### Purpose

Applies the most recent stash to the working directory but keeps it in the stash list.

### Example

```bash id="rxkqg1"
git stash apply
```

---

## Command: git stash drop

### Syntax

```bash id="v93g0d"
git stash drop <stash-id>
```

### Purpose

Deletes a specific stash entry from the stash list.

### Example

```bash id="4ulr7c"
git stash drop stash@{0}
```

---

## Command: git stash clear

### Syntax

```bash id="34u3at"
git stash clear
```

### Purpose

Removes all stash entries from the stash list permanently.

### Example

```bash id="m5ehy0"
git stash clear
```
