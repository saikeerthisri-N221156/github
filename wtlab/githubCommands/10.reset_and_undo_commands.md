# 10. Reset & Undo Commands

---

## Command: git reset

### Syntax

```bash id="1z7e9x"
git reset <commit-id>
```

### Purpose

Moves the current branch pointer (HEAD) to a specified commit.
It is commonly used to undo commits or unstage files.

### Example

```bash id="s4y3m2"
git reset a1b2c3d
```

---

## Command: git reset --soft

### Syntax

```bash id="k5n7re"
git reset --soft <commit-id>
```

### Purpose

Moves the branch pointer to a previous commit but keeps all changes staged in the staging area.

### Example

```bash id="v3o1ld"
git reset --soft HEAD~1
```

---

## Command: git reset --mixed

### Syntax

```bash id="9a8i8e"
git reset --mixed <commit-id>
```

### Purpose

Moves the branch pointer to a previous commit and removes the changes from the staging area but keeps them in the working directory.

### Example

```bash id="1l9r72"
git reset --mixed HEAD~1
```

---

## Command: git reset --hard

### Syntax

```bash id="f9o4g3"
git reset --hard <commit-id>
```

### Purpose

Moves the branch pointer to a specified commit and deletes all changes in the staging area and working directory.

### Example

```bash id="x9p1ow"
git reset --hard HEAD~1
```

---

## Command: git revert

### Syntax

```bash id="m4z3p0"
git revert <commit-id>
```

### Purpose

Creates a new commit that reverses the changes made by a previous commit without removing the commit history.

### Example

```bash id="9d5qlr"
git revert a1b2c3d
```

---

## Command: git clean -f

### Syntax

```bash id="9pg4b5"
git clean -f
```

### Purpose

Removes untracked files from the working directory.

### Example

```bash id="t1v1no"
git clean -f
```

---

## Command: git clean -fd

### Syntax

```bash id="6t5bpo"
git clean -fd
```

### Purpose

Removes untracked files and directories from the working directory.

### Example

```bash id="rqm2ui"
git clean -fd
```
