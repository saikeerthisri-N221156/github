# 1. Git Configuration Commands

## Command: git config --global user.name

### Syntax:
git config --global user.name "Your Name"

### Purpose:
Sets the username globally for all Git repositories in the system.

### Example:
git config --global user.name "keerthi-221156"

## Command: git config --global user.email

### Syntax:
git config --global user.email

### Purpose:
To set the email address that Git will attach to your commits.Also to check the connected email of the repository.

### Example:
git config --global user.email

## Command: git config --list

### Syntax: 
git config --list

### Purpose: 
Displays all Git configuration settings currently applied.

### Example: 
git config --list

## Command: git config --unset

### Syntax: 
- local: git config --unset <key>
-\if global : git config --global --unset user.email


### purpose:
Removes a specific configuration value from Git settings like:

-user.name
-user.email
-any other config key

### Example:
git config --global --unset user.email
