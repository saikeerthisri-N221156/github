# 8. Remote Repository Commands

---

## Command: git remote

### Syntax

```bash
git remote
```

### Purpose

Displays the names of remote repositories connected to the current local repository.

### Example

```bash
git remote
```

---

## Command: git remote -v

### Syntax

```bash
git remote -v
```

### Purpose

Shows the remote repository names along with their URLs for fetch and push operations.

### Example

```bash
git remote -v
```

---

## Command: git remote add

### Syntax

```bash
git remote add <name> <repository-url>
```

### Purpose

Adds a new remote repository connection to the local repository.

### Example

```bash
git remote add origin https://github.com/username/project.git
```

---

## Command: git remote remove

### Syntax

```bash
git remote remove <name>
```

### Purpose

Removes a remote repository connection from the local repository.

### Example

```bash
git remote remove origin
```

---

## Command: git fetch

### Syntax

```bash
git fetch
```

### Purpose

Downloads the latest changes from the remote repository but does not merge them into the current branch.

### Example

```bash
git fetch
```

---

## Command: git fetch --all

### Syntax

```bash
git fetch --all
```

### Purpose

Fetches updates from all configured remote repositories.

### Example

```bash
git fetch --all
```

---

## Command: git pull

### Syntax

```bash
git pull
```

### Purpose

Fetches changes from the remote repository and automatically merges them into the current branch.

### Example

```bash
git pull
```

---

## Command: git pull --rebase

### Syntax

```bash
git pull --rebase
```

### Purpose

Fetches changes from the remote repository and rebases the current branch on top of the fetched changes instead of merging.

### Example

```bash
git pull --rebase
```

---

## Command: git push

### Syntax

```bash
git push
```

### Purpose

Uploads local commits to the remote repository.

### Example

```bash
git push
```

---

## Command: git push -u origin branch-name

### Syntax

```bash
git push -u origin <branch-name>
```

### Purpose

Pushes a branch to the remote repository and sets it as the upstream branch so future pushes can be done with `git push` only.

### Example

```bash
git push -u origin main
```

---

## Command: git push --force

### Syntax

```bash
git push --force
```

### Purpose

Forces the local branch to overwrite the remote branch.
This is usually used after rewriting commit history.

### Example

```bash
git push --force
```
