# 2. Repository Setup Commands

---

## Command: git init

### Syntax

```
git init
```

### Purpose

Initializes a new Git repository in the current directory.
It creates a hidden `.git` folder that stores all repository data such as commits, branches, and configuration.

### Example

```
git init
```

---

## Command: git clone

### Syntax

```
git clone <repository-url>
```

### Purpose

Creates a local copy of an existing remote repository.
It downloads the entire project including all files, branches, and commit history.

### Example

```
git clone https://github.com/username/project.git
```

---

## Command: git clone --branch

### Syntax

```
git clone --branch <branch-name> <repository-url>
```

### Purpose

Clones a specific branch of a repository instead of the default branch.
This is useful when you want to work only on a particular branch.

### Example

```
git clone --branch develop https://github.com/username/project.git
```

---

## Command: git clone --depth

### Syntax

```
git clone --depth <number> <repository-url>
```

### Purpose

Performs a shallow clone by downloading only the most recent commits up to the specified depth.
This reduces the download size and speeds up cloning for large repositories.

### Example

```
git clone --depth 1 https://github.com/username/project.git
```
