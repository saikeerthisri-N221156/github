# 11. Rebasing Commands

---

## Command: git rebase

### Syntax

```bash
git rebase <branch-name>
```

### Purpose

Applies commits from the current branch on top of another branch, creating a linear project history.

### Example

```bash
git rebase main
```

---

## Command: git rebase -i

### Syntax

```bash
git rebase -i <commit-id>
```

### Purpose

Interactive rebase that allows editing, reordering, squashing, or deleting commits.

### Example

```bash
git rebase -i HEAD~3
```

---

## Command: git rebase --continue

### Syntax

```bash
git rebase --continue
```

### Purpose

Resumes the rebasing process after resolving conflicts.

### Example

```bash
git rebase --continue
```

---

## Command: git rebase --abort

### Syntax

```bash
git rebase --abort
```

### Purpose

Stops the rebasing process and returns the branch to the state before the rebase started.

### Example

```bash
git rebase --abort
```
