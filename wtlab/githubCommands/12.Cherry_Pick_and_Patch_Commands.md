# 12. Cherry Pick & Patch Commands

---

## Command: git cherry-pick

### Syntax

```bash id="4qj7vh"
git cherry-pick <commit-id>
```

### Purpose

Applies the changes from a specific commit on another branch into the current branch.

### Example

```bash id="h3k8vs"
git cherry-pick a1b2c3d
```

---

## Command: git format-patch

### Syntax

```bash id="i2b7qv"
git format-patch <commit-range>
```

### Purpose

Creates patch files for the selected commits, which can be sent to others for applying.

### Example

```bash id="z9l0pa"
git format-patch HEAD~2
```

---

## Command: git apply

### Syntax

```bash id="q8w3sa"
git apply <patch-file>
```

### Purpose

Applies a patch file to the working directory.

### Example

```bash id="j7x4pa"
git apply fix.patch
```

---

## Command: git am

### Syntax

```bash id="m2d1sx"
git am <patch-file>
```

### Purpose

Applies a patch file and creates a commit for each patch automatically.

### Example

```bash id="p8n6lo"
git am fix.patch
```
