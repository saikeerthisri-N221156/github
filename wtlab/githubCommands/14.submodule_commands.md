# 14. Submodule Commands

---

## Command: git submodule add

### Syntax

```bash id="v3t9fh"
git submodule add <repository-url> <path>
```

### Purpose

Adds a new Git repository as a submodule inside the current repository.
Useful for including external libraries or projects within your repo.

### Example

```bash id="p2q8kj"
git submodule add https://github.com/username/library.git libs/library
```

---

## Command: git submodule init

### Syntax

```bash id="k4s2nt"
git submodule init
```

### Purpose

Initializes submodules in your repository after cloning a project containing submodules.

### Example

```bash id="j8v7dl"
git submodule init
```

---

## Command: git submodule update

### Syntax

```bash id="f7t9uo"
git submodule update
```

### Purpose

Updates the submodules to the commit specified in the main repository.
Used to sync submodules with the main project.

### Example

```bash id="m2x5wr"
git submodule update
```
