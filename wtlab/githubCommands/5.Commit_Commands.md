# 5. Commit Commands

---

## Command: git commit

### Syntax

```bash
git commit
```

### Purpose

Records the staged changes in the repository as a new commit.
It opens the default editor to write a commit message describing the changes.

### Example

```bash
git commit
```

---

## Command: git commit -m

### Syntax

```bash
git commit -m "commit message"
```

### Purpose

Creates a commit with a message directly from the command line without opening the editor.

### Example

```bash
git commit -m "Added login feature"
```

---

## Command: git commit --amend

### Syntax

```bash
git commit --amend
```

### Purpose

Modifies the most recent commit by changing its message or adding new staged changes to it.

### Example

```bash
git commit --amend -m "Updated login feature"
```

---

## Command: git commit --no-edit

### Syntax

```bash
git commit --no-edit
```

### Purpose

Reuses the previous commit message without opening the editor.
Commonly used when amending a commit but keeping the same message.

### Example

```bash
git commit --amend --no-edit
```
