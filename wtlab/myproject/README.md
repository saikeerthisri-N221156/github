# MongoDB Integration Assignment

## Project Description
This project integrates PHP with MongoDB to implement:
- Signup
- Login
- Dashboard
- CRUD Operations

## Technologies Used
- PHP (XAMPP)
- MongoDB Community Server
- Composer

## Setup Instructions

1. Start XAMPP:
   sudo /opt/lampp/lampp start

2. Start MongoDB:
   sudo systemctl start mongod

3. Install dependencies:
   /opt/lampp/bin/php composer.phar install

4. Open in browser:
   http://localhost/github/wtlab/myproject/public/signup.html

## Features Implemented
- Create Database and Collection
- Insert User
- Read User
- Update User
- Delete User
- Duplicate Email Handling
- Password Hashing
- Input Validation
